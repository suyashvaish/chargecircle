# ChargeCircle: gap-closing report

Everything below was run in a sandbox. "Verified" means a command was actually executed and its result observed; anything
needing credentials, real third-party services, Docker or a browser is listed separately as **not verified**.

## 1. Features completed
Public data (Open Charge Map adapter wired into discovery with cache/backoff/dedupe/provenance/attribution); price transparency
(nullable prices, sources, timestamps, verified flag, "Price unavailable", estimator with working/assumptions/exclusions);
navigation (server-side destinations, Google/Apple links, optional OpenRouteService route preview, geolocation denial and manual
origin handling); vehicle profiles (unknown specs stay unknown) and compatibility with reasons and effective power; price
comparison; home-address privacy enforced on the backend (approximate pins, authorised release); server-priced bookings with
availability checks, row-locked overlap protection, PostgreSQL exclusion constraint and 15-minute holds; Razorpay order
creation, signature + provider verification, authenticated idempotent webhooks, refunds/cancellation policy; SMTP email
(verification, reset, booking, payment, cancellation, refund, reminder, security alert) with dedupe log; reviews/reports/
disputes/admin queues/audit trail; session lifecycle with manual-vs-measured energy and a recalculated-charge record; PWA
(manifest, icons, offline page, safe service worker, offline banner); Alembic migrations; production config guard; health/
readiness; structured logging; Docker/compose rewrite; accessibility/error-handling improvements on the touched screens.

## 2. Already existed and was preserved
Auth/JWT roles, station search and filters, listing creation, reliability scoring engine (with one tightening), Leaflet map,
driver/host/admin dashboards, privacy/terms/safety/support pages, seed script, the six original tests (all still pass).

## 8. Known limitations
Not settled automatically: recalculated final charge vs amount paid. No host-approval flow for non-instant listings; no push
notifications; authenticated responses never cached (offline = signed-out public browsing); PostGIS unused; older screens still
use `alert()`; tokens in `localStorage`; no general rate limiting; seed data prices are illustrative. Migration `0002` clears
18.5 INR/kWh + 0 session-fee defaults on non-sample stations (they were indistinguishable from "unknown").
